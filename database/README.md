# Database

ReLoop uses **PostgreSQL** with **Flyway** migrations. The migration files live on the backend
classpath so they are versioned and applied together with the application:

```
backend/src/main/resources/db/migration/
├── V1__init.sql                   # schema: users, profiles, tokens, catalog, scans,
│                                  #         partners, collection points, pickups,
│                                  #         collected waste, notifications
└── V2__seed_waste_categories.sql  # reference taxonomy (10 waste categories)
```

Flyway runs automatically at application start (`spring.flyway.enabled=true`), and Hibernate runs in
`ddl-auto: validate` mode — the schema is owned by the migrations, never generated by the ORM. A
startup failure on a schema mismatch is intentional: it means the entity model and the migrations
have drifted apart.

## Databases used

| Database | Used by |
| --- | --- |
| `reloop_dev` | Local development (`./scripts/dev-backend.sh`) |
| `reloop_test` | The backend test suite (`mvnw test`, profile `test`) |

Create both with `./scripts/db-setup.sh`.

## Conventions

- **UUID primary keys** generated by the application (`GenerationType.UUID`).
- **`TIMESTAMPTZ`** timestamps; the JPA layer pins the JDBC time zone to UTC.
- **Enums stored as `VARCHAR`** with `CHECK` constraints, so the database enforces the same status
  machine the services implement.
- **Foreign keys** use `ON DELETE CASCADE` for user-owned rows and `SET NULL` where the reference is
  informational (for example a collection point whose partner was removed).
- **Indexes** cover every lookup path the API exposes: history by user and date, pickups by user,
  collector and status, collection points by city and coordinates, notifications by user and read
  state.

## Adding a migration

1. Add `V<n>__short_description.sql` with the next version number — never edit an applied migration.
2. Update the affected JPA entity in the same commit.
3. Run `cd backend && ./mvnw test`; the suite starts a real database with Flyway applied, so drift
   surfaces immediately.
